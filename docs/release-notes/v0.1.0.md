Primeira release do Obsidian MCP para Obsidian Desktop.

- Servidor MCP local via Streamable HTTP, protegido por token e limitado ao localhost.
- Ferramentas para listar, ler, pesquisar e criar notas Markdown e criar pastas autorizadas.
- CLI e instaladores para Linux, macOS e Windows, com verificação de integridade e integração com o Codex.
- Atualização, diagnóstico e desinstalação que preservam as notas; as atualizações mantêm o token e as configurações existentes.

O CI passou em Linux, macOS e Windows, e as ferramentas foram verificadas em uma instalação real. **Os testes manuais nos aplicativos Obsidian e Codex em macOS e Windows ainda estão pendentes.**

Consulte o [README](https://github.com/ernando760/obsidian-mcp/blob/v0.1.0/README.md) para requisitos, instalação e configuração. Baixe os artefatos desta release e verifique-os com `SHA256SUMS`.
